**A structured framework for evaluating enterprise AI readiness on Salesforce — scoring rubrics, assessment templates, and implementation roadmaps for Data Cloud, Einstein AI, and Agentforce.**

Built by [Proxima Intelligence](https://proximaintel.com) — Enterprise Cloud & AI Consulting.

---

## Overview

The Salesforce AI Readiness Framework provides everything needed to deliver a structured 2-week AI readiness assessment for enterprises on Salesforce. It evaluates organizations across six dimensions and produces actionable deliverables including a maturity scorecard, gap analysis, and 90-day implementation roadmap.

## Who This Is For

- Enterprises in financial services, healthcare, and retail evaluating AI adoption on Salesforce
- Organizations leveraging or planning to leverage Data Cloud, Einstein AI, or Agentforce
- Teams that need a structured evaluation before committing to AI investments

## Industries (no Government)
- Financial Services
- Healthcare
- Retail & Consumer Goods

## Framework Dimensions

| Dimension | What We Evaluate |
|-----------|-----------------|
| Platform Readiness | Salesforce org structure, editions, Data Cloud config, connected apps, MuleSoft |
| Data Maturity | Data Cloud segments, data streams, identity resolution, external sources, quality |
| AI/ML Capability | Einstein AI adoption, Agentforce readiness, predictive models, use cases |
| Security & Compliance | Shield encryption, event monitoring, field-level security, data residency |
| Organizational Readiness | Executive sponsorship, admin/developer skills, AI literacy, change management |
| Integration & Governance | MuleSoft integration, API management, data governance, operational maturity |
