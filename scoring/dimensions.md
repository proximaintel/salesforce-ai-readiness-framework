# Assessment Dimensions

## 1. Platform Readiness
Evaluates the Salesforce platform's ability to support AI workloads at enterprise scale.

**Key areas:** Org structure, editions, Data Cloud activation, connected apps, MuleSoft integration, DevOps maturity.

## 2. Data Maturity
Evaluates the data platform's readiness to feed AI models with quality, governed data.

**Key areas:** Data Cloud segments, data streams, identity resolution, external sources, data quality, freshness SLAs.

## 3. AI/ML Capability
Evaluates current AI adoption, tooling, and technical readiness for scaling.

**Key areas:** Einstein AI usage, Agentforce readiness, prediction models, Next Best Action, Einstein Copilot adoption.

## 4. Security & Compliance
Evaluates the security posture specifically for AI workloads in regulated environments.

**Key areas:** Shield encryption, event monitoring, field-level security, sharing rules, data residency, Einstein Trust Layer.

## 5. Organizational Readiness
Evaluates the human and cultural factors required for successful AI adoption.

**Key areas:** Executive sponsorship, Salesforce admin/developer skills, AI literacy, training plans, change management.

## 6. Integration & Governance
Evaluates integration maturity and operational governance for AI in production.

**Key areas:** MuleSoft integration, API management, data governance, operational model, monitoring, cost management.
