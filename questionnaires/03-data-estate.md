# Data Estate Assessment

## Purpose
Evaluate the data platform maturity and readiness to support AI workloads on Salesforce.

## Questions

### Data Cloud & Storage
1. Is Data Cloud the primary customer data platform? (Yes/No/Partial)
2. Are data streams configured from external sources (S3, Azure, databases)? (Yes/No)
3. Is identity resolution producing unified customer profiles? (Yes/No)
4. How many data sources feed into Data Cloud? (1-5 / 6-20 / 20+)
5. Are calculated insights defined for AI consumption? (Yes/No)

### Data Quality
6. Are duplicate management rules active? (Yes/No)
7. Is data quality measured and monitored? (1-5 scale)
8. Are validation rules enforced on key objects? (Yes/No)
9. Is there a data stewardship process? (Yes/No)
10. Are data freshness SLAs defined? (Yes/No)

### Data Governance
11. Is field-level security properly configured? (1-5 scale)
12. Are sharing rules aligned to business requirements? (1-5 scale)
13. Is data classification applied (public, internal, confidential, restricted)? (Yes/No)
14. Is data lineage tracked from source to Salesforce? (Yes/No/Partial)

### Integration Patterns
15. What integration pattern is primary? (MuleSoft / API / Batch / CDC / Mixed)
